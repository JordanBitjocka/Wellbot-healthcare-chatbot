WellBot — Healthcare Chatbot

WellBot · Symptom Guidance Prototype

Machine learning · Flask API · Browser chat interface

View repository →

WellBot accepts a list of symptoms, predicts the most likely condition with a scikit-learn Decision Tree classifier, and returns the condition description, precautions and symptom severity through a Flask REST API — all wrapped in a lightweight JavaScript chat interface.

  • 0Symptoms encoded
  • 0Conditions classified
  • 0Training records
  • 0REST endpoints

What it demonstrates

  • Data pipeline with pandas: loading, label encoding, train/test splitting
  • Model training & probability output with scikit-learn (Decision Tree)
  • CSV-backed lookup of descriptions, precautions and severity values
  • Flask REST endpoints with CORS configured for a browser client
  • HTML/CSS/JavaScript chat UI (Bootstrap)
  • Responsible ML: clear disclaimers — educational prototype, not a medical device
